# Sprint 1 Definition of Done

每个用户故事只有同时满足以下条件才能标记 Done。当前所有检查项均未完成验收，保持未勾选。

- [ ] 功能能够正常运行
- [ ] 达到该用户故事验收标准
- [ ] 有关键路径基本测试
- [ ] 测试实际运行通过
- [ ] 关键模块 / 函数具有必要注释
- [ ] AI 生成代码经过人工 diff 审查
- [ ] Feature 合入 develop 后仍可运行
- [ ] 集成测试未破坏其他 Sprint 1 功能
- [ ] 有运行 / 测试证据
- [ ] AI 互动记录已经保留
