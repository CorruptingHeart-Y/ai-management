## 二 三个故事的实际交付

US01 由彭佳成负责，页面显示彭佳成、朱传玺、杨浩伟、何健翔的姓名和分工，成员列表与任务负责人下拉框读取同一 GET /api/members 响应。成员 id 为唯一正安全整数，接口处理空数组、非法成员与文件读取错误；页面在空列表或加载失败时禁用分配并可重试。15 项测试覆盖基本契约、预置数据、自定义数据、全部成员可分配、只读行为和错误边界。关键实现为 src/domain/member.js、src/routes/members.js、public/app.js，提交 8109119，集成 cc7c937/34b3df7。最终人工 Demo 的成员展示与负责人选择成功。

US04 由朱传玺负责，用户输入非空标题、可选描述和有效负责人后创建任务。后端拒绝空标题或不存在成员，成功返回 201，状态初始化为 TODO，任务保存至统一 JSON 文件。五项测试验证正常创建、两类非法输入、读取新任务与重新加载后的持久化。关键实现为 src/routes/tasks.js、src/db.js 和页面表单，提交 f143bd5、40b9b4e，集成 442ee8e。最终人工 Demo 的创建、选择负责人、保存和刷新读取成功。

US05 由何健翔负责，页面可将状态切换为 TODO、DOING、DONE，接口校验合法状态，非法状态返回 400，不存在任务返回 404。状态更新写回同一数据文件，页面显示中文状态。四项测试验证 TODO → DOING、DOING → DONE 及持久化、非法状态和不存在任务。关键实现为 src/domain/task.js、任务 PATCH 路由与页面状态交互，提交 8f74544、f6cad04，集成 79948a5。最终人工 Demo 两次状态转换及刷新后 DONE 保留均成功。
