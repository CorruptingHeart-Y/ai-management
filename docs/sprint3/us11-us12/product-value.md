## 端到端价值演示提纲

建议用一名团队成员的待处理工作组织演示，数据由团队预先在隔离演示环境准备。每步实际结果填写在 [验收记录](acceptance.md)；这份提纲本身不证明已经操作。

1. 在正式鉴权集成后，以合法账号登录，查看成员，创建带负责人、优先级、截止日和迭代的任务。
2. 将任务推进为 `DOING`，进入独立任务筛选页，组合负责人、迭代、优先级及关键词，说明为什么只剩下这组任务。
3. 开启迭代分组，展示指定迭代和“未归属”的区别；切到仅逾期，说明昨天截止、今天截止、已完成三类边界。
4. 返回工作台把一项任务改成 `DONE`，刷新查询，确认其退出逾期结果，US10 状态统计也随之变化。
5. 展示一个无匹配结果，并在异常/权限旅程中验证无效参数、失效登录态或权限不足均明确失败，页面清空旧结果，避免误判为仍可访问。

US02 / US03 尚未合入当前基线，因此现在不能宣称以上含登录和权限的完整旅程已通过。只读预览的结果可用于检查模块和页面，不能替代正式鉴权链路。
