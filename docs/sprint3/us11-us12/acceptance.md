# 彭佳成 Sprint 3 验收与交接

负责人：彭佳成。范围：US11 筛选任务、US12 查看逾期任务、补齐 US07 迭代视图接入及业务链路人工验收。本文是验收标准和可填写的执行表，不是已通过记录。所有人工结果、签字、时间、提交号和证据路径必须由实际执行人当场确认。

## 三条验收标准

1. **US11 组合查询可复核。** 合法查询返回 `200`；状态、优先级、负责人、迭代、逾期条件和字面关键词按 AND 取交集。迭代可选全部、指定正整数 ID 或 `unassigned`；关键词不作正则表达式执行。`tasks` 与 `matched` 一致，计数符合正式接口契约；不存在匹配时成功返回空结果。非法枚举、ID 或逾期参数返回 `400`，只读查询前后数据文件不变。依赖点：US02 / US03 合入后，仅获得任务读取授权的登录用户可以查询。
2. **US12 日期边界明确。** 以服务本地日期 `today` 判断，只有合法截止日严格早于 `today` 且状态非 `DONE` 的任务属于逾期；昨天截止未完成算逾期，今天截止、未来截止、无截止日和已完成均不算。页面的仅逾期结果、任务标识与响应日期一致；通过原工作台把逾期任务改为 `DONE` 后刷新，任务退出仅逾期结果，查询不修改其余字段。依赖点：页面与写操作需沿用正式登录态及权限，不能通过旧无鉴权路由补取数据。
3. **US07 真实视图及失败行为可点击验证。** `/task-filters.html` 从同源成员、迭代和新查询接口读取实际数据，支持筛选、分组、重置、刷新及空状态。迭代分组复用 `public/iterations.js`，未归属与未知迭代有区别；结果、组内数量与当前筛选一致。加载中、网络失败、`401` 和 `403` 均清除旧任务与旧计数并显示可理解状态；`401/403` 不回退到旧任务路由。新页面只读，修改任务返回原工作台；旧创建、状态流转、统计和持久化必须回归通过。依赖点：三个读取接口均须接入 US02 / US03 正式权限链，人工确认后才能计入发布。

以上三条是彭佳成范围的故事验收，不能替代整个项目的发布就绪 DoD。含登录/权限的结果在相应依赖未合入前只能记“待集成验证”。

## 查询与挂载交接

新路径为 `GET /api/task-query`，使用现有数据层，只读，不直接修改 `src/routes/tasks.js`。

| 项目 | 交接约定 |
|---|---|
| 可选参数 | `status`、`priority`、`assigneeId`、`iterationId`、`overdue`、`q`；省略表示该项不限 |
| 迭代参数 | 正整数 ID 或字面值 `unassigned`；其他无效值拒绝，不以类型强转放行 |
| 逾期参数 | 仅 `true` / `false`；所有条件按 AND 组合 |
| 关键词 | 字面关键词，不执行用户正则；具体搜索字段与大小写口径以 README 契约为准 |
| 成功结构 | `{ tasks, total, matched, today, overdueCount }`，各字段分母和筛选关系以正式 README 契约为准，验收时逐项核对 |
| 页面鉴权 | 同源请求，从约定的 `ai-mgmt-token` 读取已有凭证并发送 `Authorization: Bearer ...`；不把 token 写入 URL、文档或截图 |
| 鉴权失败 | `401/403` 清空结果和计数，保留明确错误；不尝试未受保护的旧接口 |
| 安全挂载适配器 | `mountTaskFilters(app, db, readAccess, { clock } = {})`，必须显式提供 `readAccess` 函数，缺少时拒绝挂载 |
| 正式挂载 | 朱传玺确认挂载点与授权契约；公共文件出口按 US02 先、US03 后串行，由当时 owner 执行薄挂载 |
| 集成限制 | 不能因预览可用就在正式环境传入空放行函数；`readAccess` 的用户身份和权限必须来自正式认证授权中间件 |

当前基线尚无 US02 / US03。`scripts/preview-task-filters.cjs` 的本机预览将现有 `createApp` 与数据层用于隔离假数据，仅监听回环地址；它的目的仅为检验模块与界面，不是正式挂载，不构成生产鉴权或发布证据。

## 端到端影响面说明

本功能位于“已登记并分配的任务 → 查找当前要处理的任务 → 回工作台推进状态 → 再次核对结果”的读取环节。筛选不创建、删除或更新任务；正式挂载复用已有 db，避免成员、迭代、任务数据分叉。

| 受影响能力 | 风险或集成点 | 本人提供的检查 | 其他负责人的接收 |
|---|---|---|---|
| US01 成员 | 负责人过滤值与真实成员 ID、无效或已失效引用 | 正常选项、空/失败态，查询不会静默换数据 | 何健翔业务复核；US03 保护成员读取 |
| US04 / US05 | 查询结果显示旧数据；状态变化导致逾期列表变化 | 创建后刷新、状态变更后刷新、持久化及只读性 | 杨浩伟正式全量回归，彭佳成人工验收 |
| US06 | 截止日和优先级默认值、日期边界和部署时区 | 昨天/今天/未来/空值/DONE 边界；旧任务兼容 | 朱传玺裁决字段与时间契约 |
| US07 | 迭代列表、指定/未归属/未知引用及组数 | 同源真实 API，复用分组模块，空结果与数量核对 | owner 确认迭代契约，彭佳成实际点击 |
| US10 | 总量、当前匹配和逾期计数容易混淆 | 以同一任务数据人工核对接口分母，不改变统计接口 | 何健翔复核总体统计与当前结果 |
| US02 / US03 | 新路径漏挂鉴权、凭证失效后保留旧数据 | 强制显式读取授权；401/403 清空且无旧路由回退 | 朱传玺与杨浩伟正式挂载和权限 E2E |
| 历史技术债 | 非原子写入、旧错误响应/失败提示、任务全量校验等仍存在 | 查询只读；新页面独立处理失败，不据此宣布旧债清偿 | 杨浩伟逐项决定清偿/降级/带债，PO 接收 |
