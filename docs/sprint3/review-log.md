## 三、审查方法（每次照做）

```bash
# 1) 看范围：先确认改了哪些文件、动了哪几行
git diff --stat <base>..<branch>
git diff <base>..<branch> -- src public test

# 2) 重点看四类：鉴权边界、错误处理、公共文件、测试断言是否被放宽
git diff <base>..<branch> -- test | grep -E '^\-' | grep -v '^---'   # 删掉的断言要能解释

# 3) 跑该故事的测试与全量回归，确认不是靠改测试变绿
node --test test/<story>.test.js
```
