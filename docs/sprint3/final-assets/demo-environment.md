# 独立演示环境准备

在安装依赖的本分支执行 `node scripts/start-demo.cjs`。工具每次新建操作系统临时目录，保留四成员、教学账号哈希、三个预置迭代和空任务，固定127.0.0.1并分配空闲端口。控制台显示实际地址和数据路径；不读取或重置真实data/db.json。凭证按现有教学约定由DRI在库外提供。

Ctrl+C停止本次演示服务；临时数据保留供核对。再次启动会生成新目录，不会覆盖上次数据；本工具不提供reset或任意真实文件覆盖选项。别把演示服务当成正式部署或生产账户系统。

可运行 `node scripts/check-demo.cjs` 自动验证演示服务：匿名401、管理员/成员登录、四成员/三迭代/空任务、创建两条不同任务、组合筛选/逾期、成员创建403且不落库、成员改状态200、DONE排除、统计一致、真实文件哈希不变、拒绝reset。结果见evidence/demo-smoke.json，共17项检查；检查结束通过IPC关闭自己启动的服务，不扫描或结束未知进程。

初次探针发生安装依赖缺失及旧Windows进程清理停滞，没有计为通过。安装依赖并将清理改为父子IPC停止后复跑成功；临时任务不写入业务数据。此证据属于实际HTTP环境冒烟，不能替代何/彭人工浏览器点击和最终演示当天检查。

现有展演Word、PPT提纲和展示脚本保持原样。实际展演、反馈、会议及签字仍由对应人员完成。
