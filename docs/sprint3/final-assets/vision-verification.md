# 原产品愿景与当前实现核对

原规划已从《第一次实验.zip》中找到，原条目为“雨课堂实验/第7组-项目规划方案.md”，抽取文本及SHA256在sources/。因此旧product-value.md中“未找到原规划”的资料缺口已经消除；本文件提供新的事实核对，不修改已有展演材料。

愿景原文为“让项目全流程透明可感”，路线为可视化→一体化→AI化；六周阶段以可视化为主，优先服务成员固定、持续迭代的小型研发团队。学生团队仅为原型试用对象，不能据此声称企业用户需求已验证。

| 原需要 | 当前候选能做什么 | 尚未兑现的部分 |
| --- | --- | --- |
| 有哪些任务、优先级如何 | 同一任务库创建、优先级、截止日、搜索和组合筛选 | 原US06独立验收标准字段及已有任务属性编辑缺失 |
| 谁负责、进度如何 | 四名成员同源分配；TODO/DOING/DONE；成员可更新状态 | 用户账号与项目成员未关联，无个人任务所有权限制；没有成员维护 |
| 本轮迭代有哪些工作 | 预置迭代、创建时归属、按迭代筛选与分组 | 原US07迭代创建/目标/日期和任务移入移出缺失，不能称完整迭代管理 |
| 逾期需要协调什么 | 未完成且截止日早于服务端本地今天的任务，DONE不误报 | 无通知或自动协调，日期依服务端本地时区 |
| 数据更新能否一致 | 列表、筛选、统计共用JSON；真实链路与重启持久化验证 | 没有生产数据库、多进程写互斥或压测保证 |
| 身份与操作边界 | 登录/登出，服务端401/403，角色管理和撤销会话 | localStorage/XSS、内存会话重启失效，不是生产鉴权加固 |

US01/04/05最小闭环、US02/03身份权限、US10统计及US11/12查询发现已有工程证据。US06/07按后续裁剪范围实现部分，原完整验收不能标为全满足。US08讨论、US09依赖、US13导出进展清单、US14成员维护、US15行动项未实现；课堂后续对US13称谓不同，原规划编号含义应保留。

开发中使用AI不等于产品已有智能拆解/排期/预测。规划甘特图也不等于平台已有甘特图模块。当前交付是透明化的可运行基础切片，产品价值还需彭佳成组织真实验用、记录反馈，由PO审定范围；本分析不生成体验评分或完成百分比。
