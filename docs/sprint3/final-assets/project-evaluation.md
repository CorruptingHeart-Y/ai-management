## AI专项评价

编码辅助将任务分解为可复用领域和路由，测试辅助发现iterations透传丢失、旧断言破坏和畸形tasks静默覆盖。回归辅助逐步覆盖错误输入、存储故障、会话失效和跨模块一致性。审查辅助暴露过度保守的成员只读权限与原US05冲突，并发现旧E2E在免鉴权工厂上通过不能证明生产权限。文档辅助汇总证据，必须以实际实现修正文档中的错误承诺。

风险同样可见：代码生成可能复制重复枚举、只覆盖正常路径；兼容探测和诊断文字可能掩盖未测能力；旧文档可能将候选写成发布或把建议带债写成已接受。采取的控制是固定测试哈希、严格真实服务旅程、递归门禁、同提交CI和待人工项分离。

人类仍负责范围、风险接受、逐故事diff审查、真实业务验收和发布决定。AI角色数量不等于独立模型数量，现有记录不能反推出每人的模型使用量或投入工时。
