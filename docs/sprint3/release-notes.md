# 爱管理 v1.0.0 发布说明（Release Notes）

状态：**草稿（待团队审定）**　拟发布日期：2026-10-20　编制：何健翔（文档智能体协作，团队审定）
适用对象：课程验收教师、组内成员

---

## 1. 版本定位

`v1.0.0` 是"爱管理"课程项目的收官发布版，覆盖三个 Sprint 的累积增量：
从最小闭环（成员—任务—状态），到任务属性与统计（优先级、截止时间、迭代、统计），
再到可登录、可授权、可筛选、可查逾期的可用原型。

## 2. 本版包含的功能

| 能力 | 说明 | 来源 |
|---|---|---|
| 查看项目成员 | 四名成员与分工，负责人下拉与此同源 | Sprint 1 · US01 |
| 创建并分配任务 | 标题非空、负责人必须存在，初始状态待办 | Sprint 1 · US04 |
| 更新任务状态 | 待办 / 进行中 / 已完成，刷新后保留 | Sprint 1 · US05 |
| 优先级与截止时间 | 高 / 中 / 低，截止日 `YYYY-MM-DD`，非法值拒绝 | Sprint 2 · US06 |
| 迭代归属 | 任务可归属某个迭代或"未归属" | Sprint 2 · US07 |
| 状态统计 | 按状态、优先级、负责人、迭代统计，独立统计页 | Sprint 2 · US10 |
| 登录 / 登出 / 会话 | 账号密码登录，token 会话，`/me` 查询当前用户 | Sprint 3 · US02 |
| 基础权限 | 角色管理与越权拦截（admin / member） | Sprint 3 · US03 |
| 筛选任务 / 查看逾期 | 按状态与迭代筛选，逾期单独视图 | Sprint 3 · US11 / US12 |

> Sprint 3 各项以合并进 `develop` 的实际状态为准：未合入的功能不写入本版，也不在演示中承诺。

## 3. 已知限制（诚实声明）

1. **会话不持久**：token 存进程内存，重启服务需重新登录（教学原型取舍，非缺陷隐瞒）。
2. **令牌存于浏览器 localStorage**：前端把 token 放 localStorage，存在 XSS 读取风险；生产环境应改为 HttpOnly Cookie 或服务端会话。教学演示可接受，不作为安全加固方案。
3. **存储为单 JSON 文件**：写入非原子、无并发控制；断电或并发写入可能损坏（TD-S2-02）。
4. **错误响应不统一**：部分异常依赖 Express 默认 500 与堆栈输出（TD-S2-03）。
5. **无实时通知、无附件、无导出**：属后续版本范围。
6. **性能未评估**：任务量在百级以内，未做压测。

## 4. 升级与回滚

- 升级：`git pull` → `npm ci` → `npm test` → `npm start`。数据文件 `data/db.json` 向后兼容，缺字段按默认值读取。
- 回滚：`git checkout v1.0.0 上一标签` 或从 `integration/sprint3` 之前的合并提交重新部署；数据文件建议先备份。
- 数据兼容：新增字段（`priority`/`dueDate`/`iterationId`/`users`）均为可选，旧数据可直接读取。
