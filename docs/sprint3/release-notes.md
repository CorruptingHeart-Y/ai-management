## 已知限制与技术债

- JSON 已采用同目录临时文件、fsync、rename，异常结构与写入失败不覆盖原文件；仍只适用单 Node 进程，不保证多进程互斥或主机断电持久性。
- 账号角色与项目 Member 是不同实体，没有按账号 ID 推断“本人任务”；目前所有已登录成员均可改任务状态。
- token 存内存、浏览器 localStorage，服务重启失效；正常刷新可恢复当前会话。存在 XSS 读取 token 风险，未经生产安全加固。
- API 关键错误以 JSON error 返回，尚无统一机器错误码。畸形文件明确失败；孤儿引用可只读诊断但禁止继续写入，需人工核实修复数据。
- TD-S2-02/03/04/05/06 已有修复与自动/浏览器工具证据，待何健翔人工复核；05已改为跨端共享运行时枚举。TD-S2-08无属性编辑接口仍建议带债，**尚待PO接受**，不能写成已经获准带债发布。
- 无实时通知、附件、导出和 AI 产品功能，未做负载测试。AI 辅助开发不是产品 AI 功能。

六项处置、理由、证据和待决策详见 [技术债台账](technical-debt-disposition.md)。

## 验证与运行

```text
npm ci --ignore-scripts --no-audit --no-fund
npm test
node --test test/e2e/main-journey.test.js test/e2e/exception-journey.test.js
node docs/sprint3/checks/release-check.cjs
npm start
```

npm test 递归发现全部 test/**/*.test.js，包括严格 E2E，拒绝失败、TODO、skip、取消、零测试。E2E 是启动真实 server.js 的 HTTP 旅程；浏览器点击验收和人工签字另行完成，不能由 HTTP 测试替代。
当前集成执行证据见 [收口记录](closeout-20261023.md)。发布自检脚本仅静态清点材料与门禁配置，不替代实际回归或人类发布裁决。

## 部署与回滚

先备份实际 DATA_FILE，保留用户未提交文件；在干净的独立部署目录检出经批准的精确 SHA，npm ci、npm test 后再运行。默认监听127.0.0.1:3000，无关闭鉴权开关。本候选前端无构建步骤。

回滚到实际记录的上一个部署 SHA，并单独评估数据兼容性；不要假设存在“上一个发布标签”，也不要用 git reset/clean 覆盖本地数据。只在明确需要且已核对路径时恢复经验证的备份。本轮没有执行真实部署切换或数据迁移。
