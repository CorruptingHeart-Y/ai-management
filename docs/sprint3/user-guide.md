# 爱管理 v1.0.0 用户手册

编制：何健翔（文档智能体协作，团队审定）　日期：2026-10-20
适用版本：`v1.0.0`（若某项功能在你的版本里点不到，说明尚未合入，以 Release Notes 为准）

---

## 1. 启动

```bash
npm ci          # 安装依赖（仅 express）
npm start       # 默认 http://localhost:3000
npm test        # 需要验证环境时先跑一遍
```

浏览器打开 <http://localhost:3000>，可见工作台；统计页在 <http://localhost:3000/stats.html>。

数据存放在 `data/db.json`。**演示前请勿用测试数据覆盖**；需要实验时用独立文件：
`DATA_FILE=/tmp/demo.json npm start`（Windows：`$env:DATA_FILE="D:\demo.json"; npm start`）。

## 2. 登录（Sprint 3 · US02）

1. 打开首页，右上角进入登录；
2. 输入账号密码（演示账号与口令由计划会纪要与团队统一提供，代码与数据只存哈希）；
3. 登录成功后页面显示当前用户与角色（`admin` 或 `member`）；
4. 退出点"登出"，token 立即失效。

> 常见问题：刷新后要求重新登录属正常现象——本版会话存在服务进程内存里，重启服务即失效。

## 3. 查看成员（US01）

工作台左侧显示四名成员与分工。任务表单的"分配负责人"下拉与此处同源，不会出现列表里没有的人。

## 4. 创建任务（US04 + US06 + US07）

1. 填写标题（必填），描述选填；
2. 选择负责人（必填）；
3. 选择优先级：高 / 中 / 低（默认中）；
4. 选择截止日期（选填，`YYYY-MM-DD`；非法日期会被拒绝）；
5. 选择迭代（选填；没有迭代时该控件隐藏，不显示假选项）；
6. 点"创建任务"。成功后任务出现在列表中，状态为"待办"。

## 5. 更新状态（US05）

在任务卡片的状态下拉里切换"待办 / 进行中 / 已完成"。刷新后状态保留。

## 6. 筛选与逾期（Sprint 3 · US11 / US12）

- 按状态筛选：全部 / 待办 / 进行中 / 已完成；
- 按迭代筛选：全部 / 未归属 / 各迭代；
- 逾期视图：只显示"截止日早于今天且未完成"的任务。
- 逾期口径为**本地日期字符串比较**（不构造时区对象），故跨时区演示不会出现一天误差。

## 7. 统计（US10）

打开 `/stats.html`：

- 四张卡片：总数 / 待办 / 进行中 / 已完成；
- 按优先级、按负责人（含 0 任务成员）、按迭代（含"未分配"）分布；
- 点"刷新"重新取数；服务不可用时显示红色错误条并提示重试，**不会把故障显示成 0 任务**。

## 8. 常见错误与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面提示"任务标题不能为空" | 标题为空或纯空格 | 填写标题 |
| "负责人无效：成员不存在" | 选了一个已被删除的成员 | 重新选择负责人 |
| "非法任务优先级 / 非法截止时间" | 传入了不在枚举内的值或无效日期 | 用下拉选择 |
| "非法迭代" | 迭代已被删除 | 改选"未归属"或其他迭代 |
| 登录返回 401 | 账号或密码错误 | 核对演示账号 |
| 统计页显示"—" | 服务不可用 | 确认 `npm start` 仍在运行，点"刷新" |
| 端口被占用 | 3000 已被占用 | `PORT=3001 npm start` |

## 9. 权限说明（US03）

- `admin`：可进行所有操作，改动会被记录；
- `member`：按角色限制写操作，越权请求返回 403；
- 越权与未登录的区分：未登录是 401（需登录），有登录但无权是 403（换账号或联系管理员）。
